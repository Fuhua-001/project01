# การเปิดใช้งาน Development Server
*วันที่บันทึก: 24 กรกฎาคม 2026*

ในการเริ่มต้นเปิดเซิร์ฟเวอร์สำหรับพัฒนาเว็บไซต์ (Development Server) เพื่อดูหน้าเว็บในเครื่องของเรา เราสามารถใช้คำสั่งได้ 2 รูปแบบหลักๆ ดังนี้ครับ:

### 1. `npm run dev`
- **คืออะไร:** เป็นคำสั่งสำหรับรันสคริปต์ชื่อ `dev` ที่เรา (หรือระบบ) เขียนตั้งค่าเตรียมไว้แล้วในไฟล์ `package.json` (ในหมวด `"scripts"`)
- **ทำงานอย่างไร:** เมื่อเราพิมพ์คำสั่งนี้ โปรแกรม `npm` (Node Package Manager) จะเข้าไปอ่านไฟล์ `package.json` หาคำว่า `dev` แล้วหยิบคำสั่งที่ซ่อนอยู่เบื้องหลัง (เช่น `next dev`) มาทำงานให้เราโดยอัตโนมัติ
- **ข้อดี:** พิมพ์ง่าย สะดวก และเป็นมาตรฐานที่นักพัฒนาโปรเจกต์ส่วนใหญ่ใช้งานกัน

### 2. `npx next dev` (ซึ่งคุณอาจจะสับสนเป็น npx run dev)
- **คืออะไร:** `npx` (Node Package Execute) เป็นเครื่องมือสำหรับ "รัน" แพ็กเกจของ Node.js โดยตรง
- **ทำงานอย่างไร:** แทนที่จะไปเรียกสคริปต์ผ่านไฟล์ `package.json` ตัว `npx` จะวิ่งไปเรียกใช้งานโปรแกรม `next` (ที่ติดตั้งอยู่ในโปรเจกต์ หรือบนอินเทอร์เน็ต) ให้ทำคำสั่ง `dev` ทันที
- **ข้อดี:** สามารถเรียกใช้คำสั่งของแพ็กเกจต่างๆ ได้โดยตรง ไม่ต้องเสียเวลาไปตั้งค่าในไฟล์ `package.json` ก่อน

*(หมายเหตุ: คำสั่ง `npx run dev` จะไม่มีอยู่จริงนะครับ เนื่องจาก npx จะใช้เรียกแพ็กเกจโดยตรง ไม่ได้ใช้รันสคริปต์เหมือน npm ครับ)*

**ผลลัพธ์ของทั้ง 2 คำสั่ง:** จะทำหน้าที่เปิดเซิร์ฟเวอร์จำลองขึ้นมา โดยปกติจะอยู่ที่ลิงก์ `http://localhost:3000` ให้เราสามารถเปิดเบราว์เซอร์ไปดูหน้าเว็บได้ครับ
