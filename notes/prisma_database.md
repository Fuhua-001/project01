# บันทึกวิธีการติดตั้งและตั้งค่า Prisma (ฐานข้อมูล PostgreSQL)
*วันที่บันทึก: 24 กรกฎาคม 2026*

สำหรับการเชื่อมต่อระบบฐานข้อมูล ทางเราเลือกใช้ **Prisma** คู่กับ **PostgreSQL** เนื่องจากเหมาะสมกับโครงสร้างข้อมูลที่ซับซ้อนของระบบ CRM 

### ขั้นตอนการติดตั้งผ่าน Terminal
หากต้องการเริ่มติดตั้ง Prisma ในโปรเจกต์ใหม่ (หรือติดตั้งใหม่ทั้งหมด) ให้รันคำสั่งตามลำดับดังนี้:

**1. ติดตั้งตัวโปรแกรม Prisma:**
```bash
npm install prisma --save-dev
```
- เป็นการติดตั้งเครื่องมือ Prisma CLI เพื่อให้เราใช้รันคำสั่งจัดการฐานข้อมูลต่างๆ ได้

**2. สร้างไฟล์ตั้งค่าเริ่มต้น (เลือกระบบเป็น PostgreSQL):**
```bash
npx prisma init --datasource-provider postgresql
```
- ระบบจะสร้างโฟลเดอร์ `prisma` และไฟล์ `schema.prisma` รวมไปถึงไฟล์ `.env` ให้อัตโนมัติ
- *(ข้อควรระวัง: หากเคยมีโฟลเดอร์ `prisma` เปล่าๆ อยู่ในโปรเจกต์แล้ว คำสั่งนี้จะทำงานไม่ผ่าน ต้องลบโฟลเดอร์เก่าทิ้งก่อนแล้วค่อยรันใหม่)*

**3. ติดตั้งตัวเชื่อมต่อฐานข้อมูลสำหรับโค้ด (Client):**
```bash
npm install @prisma/client
```
- เป็นตัวที่ทำให้เราสามารถเขียนโค้ดดึงข้อมูล เช่น `prisma.user.findMany()` ได้ในไฟล์ต่างๆ ของโปรเจกต์

### การติดตั้งแบบ Manual (กรณีมีโฟลเดอร์อยู่แล้ว)
หากมีโฟลเดอร์ `prisma` อยู่แล้วและไม่อยากลบทิ้งเพื่อรันคำสั่ง `init` ใหม่ สามารถทำเองได้ดังนี้:
1. สร้างไฟล์ `schema.prisma` ไว้ในโฟลเดอร์ `prisma`
2. ใส่โค้ดตั้งค่าเริ่มต้นลงไป:
```prisma
generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}
```
3. สร้างไฟล์ `.env` ไว้ด้านนอกสุดของโปรเจกต์ เพื่อเอาไว้ใส่ Connection String ของฐานข้อมูล

### ภาพรวมการทำงานของ Prisma (Prisma Workflow)
Prisma ทำหน้าที่เป็น "คนกลาง" (ORM - Object Relational Mapper) ระหว่าง **โค้ดของเรา** กับ **ฐานข้อมูล (Database)** โดยมีหลักการทำงาน 3 ส่วนหลักๆ ดังนี้:

**1. Prisma Schema (`schema.prisma`) - เป็นพิมพ์เขียว**
- เป็นที่ที่เราใช้เขียนออกแบบหน้าตาของตารางต่างๆ ว่าอยากให้มีคอลัมน์อะไรบ้าง (เช่น ตาราง Customer มี id, name, email) 
- เราจะเขียนด้วยภาษาของ Prisma เอง ซึ่งอ่านและทำความเข้าใจได้ง่ายกว่าภาษา SQL แบบดั้งเดิมมาก

**2. Prisma Migrate / Push - เป็นช่างก่อสร้าง**
- เมื่อเราออกแบบ "พิมพ์เขียว" ใน `schema.prisma` เสร็จ เราจะต้องสั่งให้ Prisma นำพิมพ์เขียวนั้นไปสร้างเป็นตารางจริงๆ ในฐานข้อมูล
- คำสั่งที่ใช้บ่อยคือ `npx prisma db push` (สำหรับตอนพัฒนาระบบ) ระบบจะวิ่งไปสร้างตารางใน PostgreSQL ตามที่เราเขียนไว้ทันที

**3. Prisma Client (`@prisma/client`) - เป็นพนักงานดึงข้อมูล**
- คือตัวโค้ดที่เราเอามาใช้เขียนในโปรเจกต์ Next.js ของเรา เพื่อสั่งเพิ่ม ลบ แก้ไข หรือดึงข้อมูล
- **ข้อดีที่เจ๋งที่สุด:** มันจะรู้ล่วงหน้าว่าตารางของเรามีคอลัมน์อะไรบ้าง และมีระบบ Auto-complete พิมพ์ `. (จุด)` แล้วจะมีชื่อคอลัมน์เด้งขึ้นมาให้เลือกเลย ทำให้เราเขียนโค้ดผิดพลาด (พิมพ์ชื่อคอลัมน์ผิด) ได้ยากมาก

**ตัวอย่างการทำงานทั้งหมด (Step-by-step):**
1. ตั้งค่ารหัสผ่านใน `.env` 
2. เขียนแบบตาราง (Model) ใน `schema.prisma`
3. รันคำสั่ง `npx prisma db push` ใน Terminal เพื่อนำแบบไปสร้างตารางจริง
4. ในไฟล์โค้ด (เช่น หน้าลงทะเบียน) เราก็เขียนคำสั่งง่ายๆ อย่าง `await prisma.user.create({ data: { name: "John" } })` เพื่อบันทึกข้อมูลลงฐานข้อมูลได้เลยครับ

### วิธีการเชื่อมต่อ Prisma เข้ากับ pgAdmin 4 (PostgreSQL)
เพื่อให้โปรเจกต์ Next.js ของเราสามารถส่งข้อมูลตารางเข้าไปสร้างในโปรแกรม pgAdmin 4 ที่ติดตั้งอยู่ในเครื่องได้ จะต้องทำการเชื่อมต่อ (Link) ทั้ง 2 ฝั่งเข้าด้วยกันผ่านไฟล์ `.env` ดังนี้ครับ:

**1. สร้าง Database ปลายทางให้พร้อม**
- เปิดโปรแกรม **pgAdmin 4** 
- คลิกขวาที่เมนู `Databases -> Create -> Database...`
- ตั้งชื่อฐานข้อมูล เช่น `crm_db` แล้วกด Save

**2. ตั้งค่า Connection String ในไฟล์ `.env`**
- เปิดไฟล์ `.env` ในโปรเจกต์ แล้วแก้ไขค่า `DATABASE_URL` ให้เป็นรูปแบบนี้:
  ```env
  DATABASE_URL="postgresql://[ชื่อผู้ใช้]:[รหัสผ่าน]@localhost:5432/[ชื่อฐานข้อมูล]?schema=public"
  ```
- **ตัวอย่างการใช้งานจริง:**
  ```env
  DATABASE_URL="postgresql://postgres:1234@localhost:5432/crm_db?schema=public"
  ```
  *(หมายเหตุ: `postgres` คือชื่อ User มาตรฐาน, `1234` คือรหัสผ่านที่ตั้งตอนลงโปรแกรม, `crm_db` คือชื่อฐานข้อมูลที่เพิ่งสร้างในข้อ 1)*

**3. ยิงโครงสร้างตารางเข้าสู่ Database (Push)**
- เมื่อตั้งค่า `.env` และเขียนออกแบบตารางใน `schema.prisma` เสร็จแล้ว ให้เปิด Terminal แล้วรันคำสั่ง:
  ```bash
  npx prisma db push
  ```
- หากสำเร็จ ระบบจะขึ้นข้อความว่า `Your database is now in sync with your Prisma schema.`
- คุณสามารถกลับไปเช็คที่โปรแกรม pgAdmin 4 (กด Refresh ที่ฐานข้อมูล) แล้วเข้าไปดูตารางได้ที่ `Schemas -> public -> Tables` ครับ!
