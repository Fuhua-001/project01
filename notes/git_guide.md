# บันทึกการอัปโหลดโค้ดขึ้น Git (เริ่มแรก)
*วันที่บันทึก: 23 กรกฎาคม 2026, เวลา 16:48:33 น.*

การบันทึกโค้ดลง Git (เรียกว่าการ Commit) มีประโยชน์มากเวลาเราเขียนโค้ดพลาดแล้วอยากย้อนกลับมาเวอร์ชันเดิม 
สเตปการทำงานใน Terminal:

### 1. เช็คสถานะก่อน
```bash
git status
```
- เอาไว้เช็คว่ามีไฟล์ไหนบ้างที่มีการเปลี่ยนแปลง หรือเพิ่งสร้างใหม่ (สีแดงคือยังไม่เตรียมบันทึก)

### 2. เตรียมไฟล์ทั้งหมดเพื่อบันทึก
```bash
git add .
```
- `.` หมายถึง "ทั้งหมด" เป็นการเตรียมไฟล์ทั้งหมดที่มีการแก้ไขเข้าสู่สถานะเตรียมบันทึก (Staging Area) ถ้าย้อนไปพิมพ์ `git status` ไฟล์จะเปลี่ยนเป็นสีเขียว

### 3. ถ่ายรูปบันทึกประวัติ (Commit)
```bash
git commit -m "First commit: สร้างระบบ Login และโครงสร้าง Dashboard"
```
- เป็นการบันทึกประวัติ โดย `-m` คือข้อความกำกับ (Message) เพื่อให้รู้ว่าในรอบนี้เราทำอะไรไปบ้าง

# การบันทึกและการอัปโหลดรอบถัดไป (จำง่ายๆ Add -> Commit -> Push)
เมื่อมีการแก้ไขโค้ดและต้องการบันทึกอีกครั้ง ขั้นตอนจะสั้นลงครับ

### 1. เตรียมไฟล์ที่แก้ไข
```bash
git add .
```

### 2. บันทึกและเขียนคำอธิบาย
```bash
git commit -m "ข้อความอธิบายการแก้ไขรอบนี้"
```

### 3. อัปโหลดขึ้น GitHub
```bash
git push
```
- ในรอบถัดไปไม่ต้องพิมพ์ยาวๆ แล้ว พิมพ์แค่ `git push` คำเดียวสั้นๆ ระบบจะจำเส้นทางและอัปโหลดขึ้นให้ทันที
